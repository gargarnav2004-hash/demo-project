# PMPrep AI

An AI-powered PM interview practice tool built with Next.js and the Anthropic API. Pick a category, answer one question at a time, and get an instant score + feedback from Claude.

See [CLAUDE.md](CLAUDE.md) for full context on the app, tech stack, rubric logic, and how the Anthropic API is used.

## Getting started

```bash
cp .env.local.example .env.local   # then add your ANTHROPIC_API_KEY
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

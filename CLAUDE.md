# PMPrep AI

## What this app is

PMPrep AI is an AI-powered practice tool for product manager interviews. A user
picks a question category, gets shown one interview question at a time, types
an answer, and receives a score (1-5) plus 2-3 specific feedback bullets
generated by Claude.

Flow: Hero ("Start practicing") -> category selector (6 categories) ->
practice screen (one question + textarea + submit) -> feedback panel (score +
bullets, with "Next question" / "Change category" actions).

## Tech stack

- Next.js (App Router, TypeScript, `src/` layout) + React
- Tailwind CSS v4 (theme tokens defined as CSS variables in
  `src/app/globals.css`, calm sage/off-white palette)
- `@anthropic-ai/sdk` for calling Claude from Next.js API routes (server-side
  only — the API key never reaches the client)
- `zod` + `@anthropic-ai/sdk/helpers/zod` (`zodOutputFormat`) for structured,
  schema-validated JSON output from Claude via `client.messages.parse()`

## Where things live

- `src/types/index.ts` — `Category`, `Question`, `FeedbackResult` types and
  the `CATEGORIES` tuple (Product Sense, Metrics, Estimation, Strategy,
  Behavioural, AI PM).
- `src/lib/questions.ts` — the question bank, ~5 hand-written questions per
  category, keyed by category.
- `src/lib/rubric.ts` — a short rubric (3-4 criteria) per category, used to
  ground Claude's scoring.
- `src/lib/anthropic.ts` — lazily-constructed Anthropic client, reads
  `ANTHROPIC_API_KEY` from the environment. Throws a clear error if the key is
  missing rather than silently failing.
- `src/app/api/question/route.ts` — `POST { category, excludeIds }` picks the
  next question.
- `src/app/api/feedback/route.ts` — `POST { category, question, answer }`
  scores the answer.
- `src/components/` — `Hero`, `CategorySelector`, `PracticeScreen` (owns the
  answer/submit/feedback state for one question), `FeedbackPanel`.
- `src/app/page.tsx` — client component holding the top-level view state
  machine (`hero` / `category` / `practice`) and which question has been
  asked so far.

## How the Anthropic API is used

Model: `claude-opus-4-8` (see `CLAUDE_MODEL` in `src/lib/anthropic.ts`).

Both API routes call `client.messages.parse()` with `output_config.format`
set via `zodOutputFormat(...)`, so Claude's response is validated against a
Zod schema and returned as `response.parsed_output` — no manual JSON parsing
or prompt-based "respond only with JSON" hoping.

**Question selection** (`/api/question`): the question bank for the chosen
category (minus ids already asked this session) is listed in the user
message; Claude is asked to pick the single best next question id
(`{ question_id: string }`) for variety. The app never lets Claude invent a
question — it only selects from the fixed bank, so every question a user sees
is one we've reviewed. If the picked id doesn't match a candidate (or the
call fails), the app falls back to the first candidate in the pool.

**Scoring** (`/api/feedback`): the category's rubric from `rubric.ts` is
placed in the system prompt along with the question and the user's answer.
Claude returns `{ score: 1-5, bullets: string[] (2-3 items) }`, validated by
`FeedbackSchema`.

Both routes wrap the Claude call in try/catch and return a `500` with a
plain-language error (checked by the frontend, surfaced to the user) if the
API key is missing or the call fails — there's no silent fallback that could
mask a misconfigured key.

## Rubric logic

Each category in `src/lib/rubric.ts` has 3-4 short, concrete grading criteria
(e.g. Product Sense: clarify the user, identify a real pain point, propose a
focused solution, consider how success is measured). These are handed to
Claude verbatim in the system prompt for `/api/feedback` — there's no
separate scoring algorithm; Claude applies the rubric directly and returns
the score/bullets.

## Environment variables

- `ANTHROPIC_API_KEY` — required, read server-side only in
  `src/lib/anthropic.ts`. Set it in `.env.local` (see
  `.env.local.example`). `.env*` is gitignored by the default Next.js
  `.gitignore`, so it's never committed.

## Running locally

```
npm run dev
```

Requires `ANTHROPIC_API_KEY` in `.env.local`.
